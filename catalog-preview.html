What’s in v3

  • Bottom bar — Icons + English labels. Three tabs: Home (house), Bhakti (diya), More (dots).
  • Bhakti tab — floating card — The center tab protrudes 16px above the bar with a card-like appearance (gradient bg, border, shadow) making it the focal action.
  • More tab — Contains Wishlist (saved verses with heart icon, tap-to-open) and Language selector (Hindi/English toggle cards). Also includes About & Report links.
  • Language card — Sets the default language each reader page opens in. Persisted via AsyncStorage.
  • Category icons — Each tile has a unique SVG icon (book, flame, beads, deity, lamp, music, scroll).
  • Deity icons — Rama (bow), Krishna (flute), Shiva (trishul), Hanuman (gada), Durga (shield), Ganesha (elephant).
