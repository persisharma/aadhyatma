तोरण, अठारह पर्वों पर — the garland on every festival

Decision: Option A, as prototyped. On each of the 18 catalog festivals, Home hangs a marigold toran below the wordmark with the festival's greeting chip — all day, no interruption, swaying ±0.7° (still under reduce-motion). The garland is identical on every festival; only the greeting chip changes, and it comes from the same festiveReminders.ts catalog the 07:30 notification reads, so the doorway always echoes the morning's message.

Scope locked for build: all 18 festivals (not just the star-marker majors) · toran scrolls away with the wordmark (not pinned) · no flower shower (Option C parked) · festival resolution shared with the FOR TODAY row, so the garland can never name a day the row doesn't show.

The day itself

Diwali, full Home. The toran + chip sit between the wordmark and the Today strip; everything below is the already-shipped state (festival pill, FOR TODAY leading with the festival's reading).

What ships: one FestiveToran component (SVG string + View-composed marigolds and leaves, the deity-glyph grammar — no emoji, no images), mounted in HomeScreen when today resolves to a catalog festival via a new getTodayFestival(date) helper.

  • Colours: all theme tokens — saffron, gold, saffronDeep, the card-thumb ambers. Nothing outside §2's warm palette.
  • Motion: a single 6 s alternate rotate of ±0.7°; useReducedMotion() hangs it still.
  • Type: greeting chip ≥ 10 pt (the §3.0 floor), script-aware font via the shared helpers; gu/kn re-script the Devanagari, en uses the authored greeting.
  • Layout: fixed reserved height, so the garland never nudges the Today strip mid-scroll.
