# Share generation performance follow-up — 8 November 2026

Scope: PR #657, existing and Daily Bhakti card styles through the one shared provider. Parent remote head `4cc081c4a43c0c8c405c697d2ecf99313ee0c763`.

## Fixed

1. **Cache-only share hashtags.** The previous resolver called the solving day hook. Outside the bundled 2024–2035 years, a cold Ujjain fallback synchronously solves a whole year: a fresh 2040 reproduction blocked a queued heartbeat for 1,548 ms (1,547 ms calculation) on this machine. `TimelyTagsResolver` now reads only `getCachedObservancesForDate`, filters the user's regional lenses, and subscribes to the existing observance store. A miss keeps ordinary scripture, deity and weekday tags. Sharing starts no calculation, no new download and no timer. Existing background results may enrich an open sheet; close unsubscribes. Day/city/calendar/lens changes clear or refresh the appropriate tags. The festival engine, Panchang screens, reminder dates and shared solving hook are unchanged.
2. **Separate measurement from artwork wait.** `DevotionalShareCard` reports settled native text/root geometry as soon as available, rather than waiting for every downloaded/decoded slice first. This prevents slow artwork exhausting the short 5-second measurement wait before capture reaches its existing separate 15-second art wait. Capture readiness still requires every slice, footer, body, spacer and final layout; no placeholder or guessed image can export. No timeout was increased.
3. **Less repeated generation work.** Preview and capture content identity strings are memoized across layout/paint callbacks. Mirrored paper-tile readiness advances a contiguous painted prefix rather than allocating and rescanning an N-item array after each decode. Each unique index is advanced once; duplicate/reverse callbacks remain correct. Committed shrink invalidates removed indices, so regrowth waits for re-added tile paint; changing subject/frame/width resets the tracker. This is paint-bookkeeping correctness, not native image-memory proof.

Full text, all four languages, artwork selection, fixed export fonts, PNG dimensions, preview/choice design, captions/download links and source attribution are preserved. No new package, artwork upload, permission, stored preference or release is introduced.
