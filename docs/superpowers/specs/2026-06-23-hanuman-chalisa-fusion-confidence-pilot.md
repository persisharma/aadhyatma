## How verification was done

For each language, 3 authoritative published editions were fetched and parsed into per-verse
meanings, then each of our 43 `meaningGu`/`meaningKn` was compared against the source set for
**semantic match** (same sense), cross-source agreement, and any divergence.

- **Gujarati (અર્થ / ભાવાર્થ):** sanatanjagruti.org, swaminarayanworld.net, bardaijyot.com
- **Kannada (ಅರ್ಥ):** stotranidhi.com/kn, greatindian.net, hanumanchalisapdf.in

All three sources in each language carried complete, per-verse meanings for all 43 verses, with
strong agreement among themselves — which is itself a good sign that our verse alignment is right.

**Copyright / fair use.** Source meanings were used **only to compare** — no source text was copied
into the app. App data remains our own fusion-generated text (and, for the 3 corrected verses,
text re-aligned to the published consensus). Sources are cited here for provenance.

## The 3 corrections (material divergences → fixed in `hanuman-chalisa.json`)

| Verse | Original (ours) | Issue vs sources | Corrected to |

| **chaupai-27** | "…you accomplish his **devotees'** tasks" | *तिन के काज* — 5/6 sources + the literal text read this as **Ram's** tasks (only greatindian.net used the devotee reading) | "…and you accomplish **all His** tasks" |
| **chaupai-35** | "…by Hanuman-devotion the **mind becomes focused**…" | misreads *और देवता चित्त न धरई*; **all 6** sources say "holding **no other deity** in mind, serving Hanuman alone" | "One who keeps **no other deity** in mind and serves Hanuman alone attains all joy" |
| **chaupai-38** | "…whoever practices this **repeatedly**…" | drops *सत बार*; **all 6** sources keep the specific count | "Whoever recites this **a hundred times**…" |

Provenance (both-model drafts + these corrections) is recorded in
`mobile/.translations/hanuman-chalisa.fusion.json` under each verse's `source_correction`.
