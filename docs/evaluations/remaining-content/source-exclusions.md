Searching the OCR of the [1930 Marwadi Bhajan collection](https://archive.org/details/in.ernet.dli.2015.540884) did not establish an exact match; OCR absence is not evidence of absence from the book.

Decision: do not add an unsupported active payload or copy a modern translation. The outstanding requirement is an independent full witness and a verified rights-supported source for this exact composition. B2 is explicitly incomplete. No aarti positional index has been inserted, removed or reordered. Downloading a competitor build would not resolve this provenance gap; direct textual resources already exist.
