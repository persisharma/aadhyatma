Home-Screen Widgets — विजेट

PRD-15 · Revised UI prototype: the three widgets on iOS/Android home & lock screens, the in-app gallery, and safe freshness fallbacks. Static mockups — not the live build.
Widgets are the parchment system rendered on the OS canvas: आज का श्लोक, आज का पंचांग, and जप-साधना. After foreground interactions settle, the app atomically writes a versioned 14-day payload; it also rewrites on Panchang preference, language, or Japam changes and requests a native reload. Widgets render without astronomy or network work, and Home startup never imports the Panchang graph for them. Native delivery remains behind a mandatory clean-prebuild/EAS/device Phase-0 spike.
1 · iOS home screen — the daily ambient surface
Small + medium WidgetKit sizes. The parchment card floats on any wallpaper; ॐ mark anchors the brand top-right.

Widget Gallery — preview + add instructions.
9Payload previews — each gallery card renders from the same committed payload contract as the native widget. If the payload is unavailable, the preview uses the same safe fallback instead of recomputing astronomy during render.
10Per-OS add flow — iOS shows manual long-press/Edit/Add Widget instructions because apps cannot jump into the WidgetKit picker. Android 8+ may show Add widget via requestPinAppWidget when the launcher supports it, with manual steps as fallback. No permission prompt is introduced.
Interaction inventory
① Verse widget tap → Daily Bhakti tab, today's verse (entryRoutes deep link). ② Panchang widget tap → Panchang tab for the represented IST date; city and calendar system come from the payload. ③ Japam widget tap → last-used mantra when valid, otherwise the Japam library (read-only widget in v1). ④ Missing, corrupt, incompatible, or expired payload → reverent "open Vedansh" state; tap opens the app, whose successful atomic rewrite requests a reload. ⑤ Lock-screen inline tithi/vrat tap → unlock → Panchang tab. ⑥ Lock-screen circular Japam streak → unlock → Japam counter (Phase 2). ⑦ Android widget: panchang zone → Panchang · verse zone → Daily Bhakti; compact/standard/expanded content is selected from real bounds. ⑧ More → "होम-स्क्रीन विजेट" row → Widget Gallery (plus a one-release DISCOVER card on Home). ⑨ Gallery previews render from the same validated, represented-date payload as native widgets. ⑩ "How to add" steps per OS; zero permission prompts anywhere in the flow. Native timelines schedule the next represented-date boundary. JS planning is deferred until foreground interactions settle, deduplicated and throttled; preference/language/Japam changes can also trigger it. A versioned atomic payload and explicit native reload keep failure behavior deterministic.
