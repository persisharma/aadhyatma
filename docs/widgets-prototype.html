Home-Screen Widgets — विजेट

PRD-15 · Interactive UI prototype: the three v1 widgets on iOS/Android home & lock screens, the in-app Widget Gallery, and the stale-data fallback. Static mockups — not the live build.
Widgets are the parchment system rendered on the OS canvas: आज का श्लोक (daily verse), आज का पंचांग (tithi · vrat · rahu kaal), and जप-साधना (streak ring). The app precomputes a 14-day payload into the shared container whenever it runs; widgets render natively from it — no network, ever. Every widget tap deep-links via the existing entryRoutes table.
1 · iOS home screen — the daily ambient surface
Small + medium WidgetKit sizes. The parchment card floats on any wallpaper; ॐ mark anchors the brand top-right.

Streak widget + the stale fallback.
3जप-साधना (small) — the 108-bead ring shows today's japam progress; the centre count is the day-streak from UserActivityContext. Tap → opens the Japam counter. Read-only in v1 (counting from the widget is an explicit Phase-3 App-Intents item).
4Stale state — if the user hasn't opened the app past the precomputed 14-day window, the widget never shows wrong panchang data; it swaps to this reverent prompt. Tap → opens the app, which rewrites the payload and heals the widget on the next timeline tick.

Widget Gallery — preview + add instructions.
9Live-data previews — each gallery card renders the widget with today's real values (same JS that writes the shared payload), so what the user sees is exactly what they'll get.
10Per-OS "how to add" steps — the copy switches iOS/Android wording by platform. iOS 17+ can additionally offer the system widget-picker jump; older OS versions just show the steps. No permissions are required for widgets — this screen never prompts.
Interaction inventory
① Verse widget tap → Daily Bhakti tab, today's verse (entryRoutes deep link). ② Panchang widget tap → Panchang tab, today; city follows the in-app location setting. ③ Streak widget tap → Japam counter screen (read-only widget in v1). ④ Stale window exhausted → reverent "open Vedansh" state; tap opens the app which rewrites the 14-day payload. ⑤ Lock-screen inline tithi/vrat tap → unlock → Panchang tab. ⑥ Lock-screen circular streak → unlock → Japam counter. ⑦ Android 4×2 widget: panchang zone → Panchang · verse zone → Daily Bhakti; resize 4×1/4×3 collapses/expands content. ⑧ More → "होम-स्क्रीन विजेट" row → Widget Gallery (plus a one-release DISCOVER card on Home). ⑨ Gallery previews render from today's real precomputed payload. ⑩ "How to add" steps per OS; zero permission prompts anywhere in the flow. All widget content refreshes at local midnight via the native timeline; the app refreshes the shared payload on every foreground + after the headless notification scheduler runs.
