# Vedansh 1.4.1 — App Review Information (iOS)

Notes to paste into App Store Connect → App Review Information, plus a permissions/capabilities
checklist to verify before submitting 1.4.1 for review.

## Notes for the Reviewer

- **No account or login required.** All devotional content is bundled and works fully offline
  the moment the app opens. There is nothing to sign in to and no demo credentials are needed.
- **No purchases, no ads, no user-generated content, no analytics/tracking.** The app does not
  transmit user data off the device.
- **Demo path:** Open the app → Home → tap any deity or text to read. Tap the **Panchang** tab
  for the daily almanac. Tap the **Vrat** tab to browse vrat/festival kathas.
- **Location is optional.** The Panchang tab uses *When In Use* location only to compute accurate
  sunrise/panchang times for the user's city; the coordinates stay on the device and are never
  transmitted. If location is declined, a **city picker** (default: Ujjain) provides the same
  functionality — so the reviewer can exercise everything without granting location.
- **Background audio** is used so japam (mantra) playback continues with the screen off and the
  daily-reminder sound can play; there is no microphone/recording use.

### Bottom line
The only genuinely **new** permission since 1.3.1 is **When-In-Use Location** (Panchang). Its
usage-description string is already in `app.json`, and because the coordinate never leaves the
device, no new App Privacy "data collection" declarations are required — but double-check the
App Privacy questionnaire still reads "Data Not Collected" in App Store Connect. No new
capabilities/entitlements (push, critical alerts, background location, microphone) are needed.
