11On a saved observance date, a muted ॥ स्मरण chip joins the day's observance pills — gold-toned, never the festive style, visible only on this device. Tap → person detail. This is the whole Panchang integration: one chip, no other change to the shipped day panel.
Interaction inventory
① More → पितृ स्मरण row → remembrance list. ② Pitru Paksha banner (seasonal) → fortnight overview. ③ Person card → detail. ④ + स्मरण जोड़ें → add flow (empty state carries the same action). ⑤ Mode toggle: tithi-known (month/paksha/tithi pickers) vs date-known (Gregorian input). ⑥ Computed tithi always shown for explicit confirmation — "तिथि स्वयं चुनें" overrides manually; unknown tithi saves to Sarvapitri Amavasya. ⑦ Detail solves this year + next + the Pitru Paksha day. ⑧ Reminder toggle per person, default OFF, day-before + day-of. ⑨ पाठ rows deep-link Gita adhyaya 15 / 2; delete = confirm sheet, cleans reminders. ⑩ Fortnight overview maps every saved person to their shraddha day. ⑪ Panchang day chip on observance dates → detail. No streaks, no celebration animation, no share surface anywhere in this feature.
