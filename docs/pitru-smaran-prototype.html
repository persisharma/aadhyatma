पितृ स्मरण — Tithi-Based Family Remembrance

PRD-17 · Interactive UI prototype. Static mockups in the app's parchment system — not the live build.
Managed from the More hub, but visible where devotional planning happens: a pinned ledger row in the व्रत-पर्व catalog (the My-Vrat slot) year-round, and the Home Today strip during Pitru Paksha / on family dates. Annual dates are solved by the shipped festival engine (lunarMonth + paksha + tithi → date, kshaya/adhik-aware). Muted gold-and-ink tone throughout — no streaks, no celebration, no share cards. Everything stays in AsyncStorage on this device.

Home Today strip — the seasonal touchpoint.
13Two moments, one shipped mechanism. The Today strip (§18/§32, "one observance pill + windows line") already shows each day's observance — so once PRD-17 adds the missing Pitru Paksha rules (the engine gap: `shraddha-dates` is a dead catalog placeholder today), "पितृ पक्ष — अष्टमी श्राद्ध" appears here automatically like any festival pill. On a family date (a saved person's tithi, or their Pitru-Paksha day), the muted ॥ स्मरण chip joins it → tap opens the person detail. Private, device-only, and quiet — no NEW badges, no counters on Home.
Interaction inventory
① More → पितृ स्मरण row → remembrance list. ② Pitru Paksha banner (seasonal) → fortnight overview. ③ Person row (ObservanceList row pattern §33, soonest-first) → detail (ObservanceDetail hero pattern). ④ + स्मरण जोड़ें → add flow (empty state carries the same action). ⑤ Mode toggle: tithi-known (month/paksha/tithi pickers) vs date-known (Gregorian input). ⑥ Computed tithi always shown for explicit confirmation — "तिथि स्वयं चुनें" overrides manually; unknown tithi saves to Sarvapitri Amavasya. ⑦ Detail solves this year + next + the Pitru Paksha day. ⑧ Reminder toggle per person, default OFF, day-before + day-of. ⑨ पाठ rows deep-link Gita adhyaya 15 / 2; delete = confirm sheet, cleans reminders. ⑩ Fortnight overview maps every saved person to their shraddha day. ⑪ Panchang day chip on observance dates → detail. ⑫ व्रत-पर्व catalog: pinned पितृ स्मरण row under My Vrat (§33 pinned-row treatment, live count + next date) → remembrance list. ⑬ Home Today strip: Pitru Paksha observance pill (automatic once the paksha rules exist) + the ॥ स्मरण chip on family dates → person detail. No streaks, no celebration animation, no share surface anywhere in this feature.
