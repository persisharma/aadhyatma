The proposed होम and पाठ surfaces rebuilt in the app's parchment system, token-exact from colors.ts, on Saturday 5 September 2026 in Ujjain, the day and city of the reference screenshots.
Two changes from the first pass: the आज का पंचांग strip is kept exactly as shipped — it is not merged into a larger card, and it still opens the Panchang tab, nothing else. The दैनिक श्लोक card is removed from Home entirely; the daily verse stays exactly where it already lives, on the भक्ति tab, untouched. With nothing on Home embedding Ask any more, the floating search button is back too.
What the prototype still claims: below the untouched strip and FOR TODAY row, one साधना row replaces three separate doors to the same routine/sankalp/japam state, a fixed उपकरण row replaces tools scattered across tiles and Discover cards, and नया replaces the shuffled carousel with only what this user has not opened yet. The text library moves one level down, reached from a single पाठ row rather than ten grid tiles.
Real vs illustrative: the panchang headline and the अभिजीत/राहु काल windows, Ganesh Chaturthi on Mon 14 Sep, and every category count come from the shipped data. Streak, follow counts, and the "जारी रखें" position are illustrative placeholders.

Constraints the prototype honours

  • First frame is the final frame (§64). The Today strip is untouched, so this was already true; the साधना row and the उपकरण row must reserve their height the same way, so nothing shifts once their data lands.
  • Festival first. The toran, the leading आज के लिए card, the strip's own chips, and the morning notification all read the same festive catalog and observance rule, so all four keep naming the same day.
  • भक्ति stays untouched. The daily-verse pool selector, the widget deep link, the reminder, and design.md §23 are exactly as shipped — none of that machinery is touched by removing the Home card.
  • Row 2's पंचांग/अन्य reorg is a separate idea. It carries its own contract changes (design.md §37 for अन्य, a new § for the परिवार block) whenever it's taken up — it is not part of today's Home revision.
