# Speech inside painted artwork — 2026-10-13

The user rejected both the separate parchment speech gutter and fixed-top bubbles whose capped tails stopped far above the cast. This revision replaces all 31 dialogue illustrations with reviewed, fully painted portraits and anchors each balloon beside its actual speaker. The other 109 panels retain their reviewed art and frames. All 140 panel IDs, Hindi/English narratives, source references and page transitions remain unchanged.

## Placement contract

`mobile/src/data/comicSpeechLayouts.ts` records a body edge and a speaker endpoint for each scene. Text grows upward from that edge as language/size changes; the tail reaches its recorded endpoint without a universal length cap. The central white-robed Vashishtha, kneeling Dasharatha, Shunahshepa and inverted Trishanku have explicit targets. Trishanku's bubble sits below his inverted head inside painted sky, with an upward tail, so the pointer never crosses his body. Narration remains in its own caption above the illustration. Accessibility retains speaker names.

All selected portraits retain their full painted bounds. Dialogue fits inside the art at Standard/Large, including narrow screens; extreme accessibility text flows below it without clipping. Native pages use 8-point side gutters, compact shared header/language controls and vertical scrolling. They retain the app's global text sizing and safe-area ownership.

The authoring browser uses the exact native placement/path functions, generated by `npx --prefix mobile tsx mobile/scripts/sync-comic-speech-layouts.ts`. Regenerate `speech-layouts.js` whenever placement code changes. No independent browser geometry constants should drift from the app.
