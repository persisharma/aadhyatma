# Aranyakanda illustrated preview: authoring draft

**Status: draft for review; not ready for artwork or app integration.** This package continues the complete Aranyakanda plan in [aranyakanda-plan-v1](../aranyakanda-plan-v1/README.md). It records a fresh pass through the selected local source arc and carries the 91-page / 256-scene outline into an authoring workspace. It does not replace the existing planning package or certify the story for illustration.

## Included

- [page-plan.json](page-plan.json): provisional page grouping, scene intents, introductions, and handoff cues for all 75 sargas.
- [source-reading-review.json](source-reading-review.json): reading scope and source-corpus hash, the 2,439 traversed local records, recovery of a truncated reading batch, and known source-data issues.
- [source-fetches.json](source-fetches.json): publication access results and hashes. On 2026-10-27, 73 English chapter pages were retrieved; two were unavailable. All 75 Hindi chapter requests returned HTTP 406. Retrieval is evidence of access only, not collation or editorial acceptance.
- `scripts/`: repeatable source retrieval and bounded local-corpus reading helpers. Retrieved publication HTML is kept outside the repository; no source-page text is redistributed here.

## Open work

1. Complete independent passage collation, including the Hindi publication and the recorded numbering/meaning discrepancies.
2. Author and review all 91 pages in Hindi, English, Gujarati, and Kannada. The current titles and scene intents are not complete scripts.
3. Review the whole adaptation and every transition with a human editor, including sensitive and relationship-specific dialogue.
4. Measure the four scripts at the actual reader sizes, revise page rows, and only then create and inspect distinct artwork.
5. Present the complete illustrated book for review before any native reader integration.

This draft is a source-reading and story-outline milestone only. It does not establish source collation, complete four-language narratives, human editorial approval, art, layout, device, CDN, or release acceptance.
