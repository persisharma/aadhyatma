# Wave 8 plate prompts — the regional / one-per-state rows

Every Theerth temple that carries a full §12.6 reading must ship its own
1024×1024 parchment sketch. `backgrounds.coverage.jest.test.ts` fails a temple
that has `sections` but no entry in `theerthBackgroundOverrides`, so **the plate
comes first and the text follows**.

Remote Claude Code sessions have no image-generation tool, so these plates are
produced outside the repo. Below is one ready-to-paste prompt per temple, built
from the RULEBOOK §11.8 template with the subject set to *that* temple's
distinctive murti / sanctum (§12.6 item 10). Paste a prompt into whichever image
model you use, then follow the registration checklist at the bottom.

**House rules baked into every prompt:** aged sepia ink-and-pencil on parchment,
warm monochrome, subject anchored top-centre, bottom third left empty for text
overlay, no lettering or watermark, square 1024×1024.

---

## 1. Konark Sun — `konark-sun` · Konark, Odisha

```text
Create a faded, vintage hand-drawn devotional illustration of the Konark Sun temple, in the style of an aged sepia ink-and-pencil sketch on old parchment, like a soft antique lithograph. Understated, low-contrast, not vivid, not saturated, not photorealistic.

Subject: one of the temple's great carved stone chariot wheels, its spokes and hub richly sculpted, set against the base of the towering jagamohana with its stepped pyramidal roof, and a standing Surya figure carved in a wall niche above, holding lotuses. Use a calm, devotional framing. Supporting elements may include faint outlines of the seven stone horses and a low sea horizon, but keep them faint and uncluttered.

Palette: warm monochrome sepia, muted cream and brown tones only. No bright yellows, no strong colors. Soft faded pencil linework, gently fading toward the edges.

Composition: square 1:1 frame. Anchor the subject in the upper-center / top half of the image. The bottom third must remain mostly empty plain parchment negative space for app text overlay. Keep the illustration calm, devotional, readable, and not busy.

Background: plain aged parchment with subtle paper grain and very soft edge wear. No hard border, no decorative frame, no readable text, no lettering, no captions, no watermark, no logo, no UI elements.

Format: 1024 x 1024 PNG.
```

## Registration checklist (per plate)

Artwork lives in the upper part of every plate; the detail screen anchors the
square to the **top** of a 5:4 window, so keep the subject high.

1. Convert to WebP and save as `mobile/assets/backgrounds/theerth-<id>.webp`.
   Existing plates run roughly 125–280 KB.
2. Register the asset in `mobile/assets/backgrounds/index.ts` as
   `theerth_<id_with_underscores>`.
3. Add the id to `theerthBackgroundOverrides` in `mobile/src/data/backgrounds.ts`.
4. Add the id to `dedicatedTheerthBackgroundIds` in
   `mobile/src/data/__tests__/backgrounds.coverage.jest.test.ts`.
5. Add the temple to the plate list in design.md §27 item 4.

Steps 2–5 can also be left to the temple's own `/enrich-theerth` session — it
does them as part of shipping the reading, provided the `.webp` is already in
the repo. Dropping in the nine files is enough to unblock the whole wave.

## Then run the readings

One fresh session per temple, never batched:

```
/enrich-theerth konark-sun
/enrich-theerth vishnupad-gaya
...
```

Order suggestion: Lakshmi Narayan, Vishnupad, Shree Govindajee and Durgiana
first — they have the strongest dated sthapana and district / trust sourcing, so
they set the depth bar for the rest of the wave. Konark is an ASI monument rather
than a living shrine; expect its `parampara` / `mela` to lean on Chandrabhaga Mela
and the Konark Dance Festival, and record every "sources have nothing" drop in
the PR.
