Namkaran — नामकरण

PRD-17 · UI/UX prototype. Static mockups in the app's shipped parchment system — not the live build.
Enters through Panchang → ज्योतिष, below अष्टकूट मिलान, and pushes inside the existing Panchang stack. The calculation is one sidereal Moon longitude → charana (pada) → नामाक्षर; the naming-day muhurat door lands on the already-shipped EVENT_RULES.namkaran occasion. No birthplace is requested (the charana is geocentric), no Kundali autofill (that is an adult's chart), and an unknown birth time yields a set of candidate syllables with IST windows — never a hidden noon. Every screen here is assembled from shipped components: ReaderHeader, Home's 3-column CategoryCard launcher for the 27 nakshatras, ListCard, BirthDetailsForm, CalendarDatePicker/ClockTimePicker, ShareButton, the 4:5 share-card family.

The Jyotish landing has three cards today (Kundali, Rashifal, Guna Milan). Namkaran becomes the fourth. Input asks for date and time only — and offers the no-birth-data path with equal weight.

9The Moon covers ≈ 3.6–4.5 charanas a day, so an unknown birth time honestly means 3–5 candidate syllables.
