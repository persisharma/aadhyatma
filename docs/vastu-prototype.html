वास्तु — Directional Dharma of the Home

PRD-20 · Interactive UI prototype. Static mockups in the app's parchment system — not the live build.
A calm reference tool, not a verdict machine — no dosha language, no warning colour, no remedies. Lands in the Panchang stack beside Kundali and Rashifal (no new Home category; the launcher grid is closed at 5×3). Centrepiece is a tappable Vastu Purusha Mandala — a 3×3 View-composition grid (8 dik + ब्रह्मस्थान), no images, no SVG. Direction pages hand off to shipped texts (Kubera → कुबेर स्तोत्र); the facing guide answers "मुख्य द्वार किस दिशा में?" with a picker, never a sensor. Classical quotes render only after two-source verification (RULEBOOK §11) — the slot shows its honest pending state here. Cross-linked from the Muhurat Finder's गृह प्रवेश and भूमि पूजन results.

108 facing cells, 2×4 — cardinal facings lead, intercardinal follow. No compass: `expo-sensors` is a native module (store release), and a wrong magnetometer reading in an RCC-heavy building would be worse than asking. The one-line definition above the grid resolves the classic "facing which way?" confusion before it happens. Selection is operable without gesture (plain taps), and optionally persists as one AsyncStorage key.
