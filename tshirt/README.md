# Vedansh — "Manuscript Crest" T-Shirt

A T-shirt design inspired by **Vedansh** (वेदांश़), the offline-first Hindu
devotional-text reader in this repo. The goal was *not* to invent a new look but
to wear the app's own identity — so every element is lifted straight from
[`design.md`](../design.md).

> **Open [`preview.html`](./preview.html) in a browser** to see it on shirts
> (the Devanagari renders via the brand's Google Fonts). The print-ready artwork
> is [`vedansh-emblem.svg`](./vedansh-emblem.svg).

## The concept

A single **altar-like crest** worn over the heart — *reverent, not decorative*
(design.md §1). It reuses the app's exact building blocks:

| Element | Where it comes from |
|---|---|
| `ॐ` focal glyph + `वेदांश़` wordmark | the Home **wordmark lockup** (§5) |
| `॥` between two saffron rules | the **verse divider** ornament (§5) |
| `॥ श्रीरामचन्द्र चरणौ शरणं प्रपद्ये ॥` | the Home-screen **footer mantra** (§7) |
| *Sacred Texts · Daily Reading* | the Home **tagline** (§18), Cormorant italic |
| `ॐ श्री गणेशाय नमः` arc | an opening invocation, set on the medallion ring |
| medallion rings | saffron-deep + gold, the app's two accents |

Nothing is added that the app doesn't already say. The crest is the wordmark,
the divider, and the mantra — composed into one mark.

## Tokens used (all from `design.md` §2–3)

- **Type:** Noto Serif Devanagari (all Devanagari) · Cormorant Garamond italic (Latin tagline)
- **Cream colorway** (natural/parchment tee): `ink #1A0E03`, `ink-soft #5A3A1E`,
  `saffron #B8621B`, `saffron-deep #8A3E0B`, `gold #A67C34`
- **Ink colorway** (deep charcoal tee): light-on-dark — parchment inks
  (`#F8EFD6`/`#E9D9B1`) with brightened saffron/gold (`#D9893F`/`#C9A24A`) so the
  accents survive on a dark ground.

## Placement options (in the preview)

1. **Front print** — full crest centered on the chest (both colorways).
2. **Left-chest crest** — compact `ॐ` + `वेदांश़` only, pocket scale.
3. **Back yoke** — the footer mantra across the shoulders.

## Print notes

- `vedansh-emblem.svg` is **vector** → scales to any size with no quality loss.
  Recommended front-print width: **10–11 in** on an adult tee.
- For screen-printing, the cream colorway separates into **3 spot colors**
  (ink, saffron/saffron-deep can share a screen as a single saffron + a darker
  outline, gold). For lowest cost it also reads well as a **1-color** print
  (all `ink`, or all `saffron-deep`) — drop the gold ring and the saffron rules
  to the single ink color.
- The Devanagari uses Noto Serif Devanagari. Before sending to a printer,
  **convert text to outlines/paths** (e.g. Inkscape → *Path ▸ Object to Path*),
  since the print shop won't have the font installed.
- Suggested garment colors: natural / sand / oat (cream colorway) or
  espresso / charcoal (ink colorway) — warm tones that echo the parchment base.
