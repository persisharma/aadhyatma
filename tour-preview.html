Behavior & Mechanics

  • First install — Tour shows automatically once fonts load & splash hides. Marks both tour-completed-v and whats-new-seen-v in AsyncStorage so the user is not double-prompted.
  • Update launch — Tour stays dormant. What’s New modal fires once, listing only the features added in the current version (per the whatsNew['1.4.0'].items array).
  • Skip / Back / Next / Done — Skip on any page ends the tour immediately. Back is disabled on step 1. Done on step 6 marks the tour complete.
  • Bilingual — Every tour page renders Devanagari (primary) and English (secondary) since the user has not picked a reading language yet. The What’s New modal honors the chosen language (Hindi or English variant shown above).
  • Adding a new version — Bump APP_TOUR_VERSION in data/tour/whatsNew.ts to match app.json & add a new keyed entry with the new features.
  • Replay — More → Show Tour Again calls resetTour(), clears both storage keys, and re-opens the tour on the spot.
